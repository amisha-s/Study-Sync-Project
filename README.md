# Study-Sync-Project
StudySync is a responsive landing page project built with HTML5 and CSS3. It showcases a modern education platform with sections for features, testimonials, newsletter signup, and footer navigation.

📌 Features
Responsive header with navigation links, logo, and hamburger menu for mobile.

Hero section introducing the platform with call-to-action buttons.

Trusted By section highlighting partner companies.

Feature cards showing competitive advantages with distinct colors and icons.

Testimonials with hover effects and user avatars.

Newsletter signup form with styled input and button.

Footer with company info, social links, and multi-column navigation.

🛠️ Tech Stack
HTML5 for semantic structure

CSS3 for styling and responsiveness

Google Fonts (Inter) for typography

Flexbox & CSS Grid for layout

Media Queries for mobile responsiveness

📱 Responsiveness
On desktop, navigation links and the "Contact Us" button are visible.

On mobile, the navigation collapses into a hamburger menu.

Feature grid collapses into a single column on smaller screens.

Newsletter image hides on mobile for better layout.

🎨 Design Highlights
Smooth animations (slideFromLeft) for hero section.

Hover effects on testimonial cards.

Consistent color palette using CSS variables.

📝 Usage Instructions
Navigation: Click links in the header to jump to sections. On mobile, use the hamburger menu.

Hero Buttons: “Start Now” and “Take Tour” are styled CTAs.

Feature Cards: Hover to see distinct background colors.

Testimonials: Hover over cards for scale and shadow effects.

Newsletter: Enter email and click Send (currently non-functional).

Footer: Explore product, company, support, and legal links.
